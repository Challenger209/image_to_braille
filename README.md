# 盲文像素画（Image-to-Braille）使用手册

本工具用于将普通图片转换为由 Unicode 盲文字符（Braille Patterns）组成的字符画。程序内置了局部自适应、全局阈值、边缘检测三种核心处理算法，并提供对比度增强、多分辨率控制等功能。

---

## 📦 1. 环境准备

### 1.1 获取代码

```bash
git clone https://github.com/Challenger209/image-to-braille.git
cd image-to-braille
```

如果是下载 ZIP，解压后进入项目目录即可。

### 1.2 安装依赖

本程序需要 Python 3.8+，依赖项记录在 `requirements.txt` 中：
```bash
python -m pip install -r requirements.txt
```

### 1.3 准备输入图片

仓库不附带示例图片，请准备本地图片，并在命令中将 `input.jpg` 替换为实际路径。

### 1.4 终端显示建议
盲文字符 `⠁` 在绝大多数终端字体中，**宽高比不是 1:1**（通常是 1:2，即高度是宽度的两倍）。程序内部已经针对 8 点盲文（2x4 像素）和 6 点盲文（2x3 像素）做了比例补偿，但不同的终端（如 VS Code, iTerm2, CMD）字体渲染仍会有细微差别。
**建议**：将输出结果保存为 `.txt` 文件，使用 VS Code、Notepad++ 等工具并开启等宽字体查看，效果最佳。

---

## 🚀 2. 快速开始

最基础的用法只需要提供图片路径：
```bash
python image_to_braille.py input.jpg
```
默认使用 80 个字符宽度、8 点盲文、`adaptive` 模式，并将结果打印到终端。

若要保存到文件，加上 `-o` 参数：
```bash
python image_to_braille.py input.jpg -o output.txt
```

自动调参可使用 `--auto`：
```bash
python image_to_braille.py input.jpg --auto
```
未指定 `--mode` 时，程序会根据图像对比度和边缘复杂度评分选择模式；指定 `--mode` 后，`--auto` 只在指定模式下调整参数。评分会轻微偏向 `adaptive`，并降低 `edge` 被选中的权重。自动处理完成后，会额外输出一条 `[可复现命令]`；该命令包含自动选择出的模式和最终有效参数，并关闭再次自动调参，因此可以直接运行得到相同的盲文结果。

程序会根据当前操作系统生成复现命令：Windows 路径包含空格时使用双引号格式，兼容 CMD 和 PowerShell；Linux/macOS 使用适合 Bash/Zsh 的格式。

## 📖 3. 全参数详解

程序中所有可调参数按功能分为四类：**基础画幅**、**核心模式**、**模式专属参数**、**通用预处理**。

### 3.1 基础画幅控制参数

| 参数指令 | 默认值 | 推荐范围 | 作用与调参说明 |
| :--- | :--- | :--- | :--- |
| `-w, --width` | `80` | `60 ~ 150` | **决定输出宽度（字符数）**。<br>• 越小越抽象（适合极简图标）<br>• 越大细节越多，但过大（如>150）会导致像素拥挤成一团黑 |
| `--height` | `自动` | 无需填 | **强制设定输出高度**。<br>• 默认根据原图比例自动计算，**强烈建议留空**，手动修改会改变图片长宽比（变胖或变瘦） |
| `--six` | `关闭` | 开关参数 | **切换为 6 点盲文（2x3 像素）**。<br>• 8 点（默认）：2x4，画面更方正<br>• 6 点：2x3，画面更瘦长，总字符数更少 |
| `--invert` | `关闭` | 开关参数 | **在模式处理前反转灰度值**。<br>• 对 `global` 效果最直接<br>• 对 `adaptive` 的结果会受 `--adaptive-c` 影响，尤其 `C≤0` 时可能出现明暗极性反转<br>• `edge` 使用 Canny 梯度幅值，整体反色通常不会改变边缘结果<br>• 如果图片是**黑底白线**，可先尝试此参数 |
| `-o, --output`| `无` | 文件路径 | **保存到文本文件**。<br>• 不加此参数直接打印在终端 |

### 3.2 通用预处理参数

| 参数指令 | 默认值 | 推荐范围 | 作用与调参说明 |
| :--- | :--- | :--- | :--- |
| `--enhance` | `1.0` | `1.0 ~ 3.0` | **对比度增强**。<br>• 原图灰蒙蒙时设为 `1.5` 或 `2.0`，能拉开明暗差距<br>• 会先于缩放执行，对三种模式都有效 |

### 3.3 核心模式选择 `--mode`
决定图片以何种方式提取特征，可选值：`adaptive`（默认）、`global`、`edge`。未指定 `--mode` 时使用 `adaptive`；未指定模式并使用 `--auto` 时由程序评分选择；如果显式指定模式，`--auto` 只优化该模式的参数。

#### ① `--mode adaptive` （局部自适应模式）
*   **原理**：不看全图，计算每个像素周边邻域的平均值，根据该局部平均值判定明暗。
*   **适用**：二次元/动漫图、光影不均的风景照、渐变色背景、局部过暗或过亮的图。
*   **专属参数**：
    *   `--adaptive-block` （默认 `3`）：**计算邻域的大小（必须大于等于 3）**。小于3的数自动取3，偶数会自动加 1 转为奇数。
        *   设为 `3` 或 `5`：极度敏感，画面更细致。
        *   设为 `15` 或 `21`：视野更广，忽略小噪点，抓大块明暗对比。
    *   `--adaptive-c` （默认 `6`）：**微调惩罚常数**。
        *   **调大（7~15）**：必须比周围亮/暗非常多才算数，画面更干净。
        *   **调小（1~5）**：稍微有点暗就亮起，画面更密更实。`C≤0` 时，黑白极性可能与直觉相反。
    *   *注：在此模式下，`--threshold` 参数不生效。*

#### ② `--mode global` （全局灰度模式）
*   **原理**：将图片转灰度，全图使用同一个固定阈值判定明暗。
*   **适用**：二次元插画、对比度极高的图、纯色背景图。
*   **专属参数**：
    *   `-t, --threshold` （默认 `128`）：
        *   **调高（160~200）**：更多像素被判定为暗，画面更实、更黑。
        *   **调低（50~100）**：只有极暗的像素算作凸点，画面更空、更亮。

#### ③ `--mode edge` （Canny 边缘线稿模式）
*   **原理**：计算相邻像素的梯度差值，只提取图片的轮廓线。
*   **适用**：带明确线条的图、写实照片（提取线稿）、想要干净素描感的效果。
*   **专属参数**：
    *   `--edge-low` （默认 `50`）：**弱边缘阈值**。
        *   **调低（20~30）**：抓取细节，容易产生噪点。
        *   **调高（80~100）**：只抓取明显的粗轮廓。
    *   `--edge-high` （默认 `150`）：**强边缘阈值**。
        *   通常设为 `edge-low` 的 2~3 倍。如果长线条断断续续，可以适当调低；如果杂线太多，可以调高。

#### ④ `--auto` （自动模式）
*   **原理**：先根据缩放后的图片计算对比度和边缘复杂度，再为 `adaptive`、`global`、`edge` 三种模式评分。
*   **选择倾向**：`adaptive` 有轻微优先级，`edge` 的评分会适当降低，避免边缘噪声导致过早选择线稿模式。
*   **推荐用法**：先运行 `--auto`，根据输出的最终参数和 `[可复现命令]` 确定一个基线；再分别尝试 `--mode adaptive`、`--mode global` 或 `--mode edge`，选择视觉效果更好的结果。

`--target-density`（默认 `0.30`，建议范围 `0.1~0.5`）是自动调参时的目标参考值，不保证三种模式的最终密度都完全达到该值。复现命令会保留该参数，但不会再次开启自动调参。

## 🛠️ 4. 调参标准工作流 (SOP)

拿到一张新图，按照以下步骤依次尝试，可以最快得出完美效果：

1.  **先用自动模式建立基线**
    *   运行 `python image_to_braille.py 图.jpg --auto`，根据输出的参数和 `[可复现命令]` 生成基线结果。尝试微调宽度、参数等得到更好的效果。

2.  **再比较其他模式**
    *   可分别使用 `--mode adaptive`、`--mode global`、`--mode edge`；如果希望让指定模式自动调参，再加 `--auto`。
    *   建议先试 `adaptive`，适用于大多数情况
    *   **二次元/动漫图**：优先尝试 `adaptive`、`global`。
    *   **光影复杂/背景杂乱**：优先尝试 `adaptive`。
    *   **线稿**：尝试 `edge`，适合需要突出轮廓的情况。

3.  **各模式微调**
    *   **自适应模式 (`adaptive`)**：
        *   太密：`--adaptive-c 10`
        *   太稀：`--adaptive-c 4`
        *   细节太碎、噪点太多：增大 `--adaptive-block 15` 或 `21`
        *   细节不足、画面过于平滑：减小 `--adaptive-block 3` 或 `5`
        *   `--adaptive-block` 必须至少为 `3`，偶数会自动加 `1` 转为奇数
    *   **全局模式 (`global`)**：
        *   太黑：`-t 100`
        *   太白：`-t 160`
        *   `--threshold` 越低，凸点越少；越高，凸点越多
    *   **边缘模式 (`edge`)**：
        *   细节或线条丢失：降低 `--edge-low 30`，必要时降低 `--edge-high 80`
        *   噪点太多：提高 `--edge-low 70` 和 `--edge-high 180`
        *   `--edge-high` 通常设置为 `--edge-low` 的 2~3 倍

4.  **通用参数微调**
    *   图像太小或细节不足：增大 `--width`，例如 `-w 100`
    *   图像比例异常：不要手动设置 `--height`，让程序按原图比例自动计算
    *   图像灰度差异不足：尝试 `--enhance 1.5` 或 `--enhance 2.0`
    *   黑底白线图片：尝试 `--invert`；但 `edge` 模式通常不会因整体反色而改变边缘结果
    *   使用 `--auto` 时：通过 `--target-density` 调整目标凸点密度，建议范围为 `0.1~0.5`

## 🚑 6. 常见故障排查 (Troubleshooting)

| 问题现象 | 可能原因 | 解决方案 |
| :--- | :--- | :--- |
| **满屏空白 `⠀⠀⠀`** | 1. 阈值太低，全图都被判定为亮部。<br>2. 原图是黑底白线，但没加 `--invert`。 | 1. 增加阈值：`-t 180`<br>2. 加上 `--invert` 参数 |
| **满屏实心 `⣿⣿⣿`** | 1. 阈值太高，全图都被判定为暗部。<br>2. 原图极暗。 | 1. 降低阈值：`-t 80`<br>2. 加上 `--invert` 或改用 `edge` 模式 |
| **图案模糊像浆糊** | `-w` 设得太大（如 >150），网格不够用了，所有点挤在一起。 | 降低宽度：`-w 80`，或者改用 `--mode edge` 提取线稿。 |
| **图像上下被严重拉长** | 终端字体的宽高比问题。 | 保存到 txt 文件用代码编辑器看，或调整终端的行高/字体比例。 |
| **边缘检测模式断线严重** | `--edge-high` 或 `--edge-low` 设置不合适。 | 降低 `--edge-high`（如降到 `80`），或降低 `--edge-low` 以保留弱线。 |
